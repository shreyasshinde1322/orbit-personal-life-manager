# Orbit Week 2 Wireframes

This folder contains the Week 2 UI wireframe and database design materials. The Android app source code and Gradle project are kept separately in the repository's `code` folder.

- `screenshots/` contains prototype wireframe screens.
- `screen-descriptions.md` describes the screens and interactions.
- `navigation-flow.svg` shows the primary navigation.
- `orbit-er-diagram.svg` shows the data model.
- `week2-report-outline.md` contains the report outline.
